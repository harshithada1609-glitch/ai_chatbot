# 🤖 BrainByte – AI Interview Assistant

BrainByte is an AI-powered Interview Assistant built using Flask, Groq API, HTML, CSS, and JavaScript.

It helps users prepare for:
- HR Interviews
- Python Interviews
- Data Science Concepts
- AI & Machine Learning Topics
- Resume-Based Questions
- Technical Interview Preparation

---

# 🚀 Features

✅ Real-time AI Chatbot  
✅ Typing Animation  
✅ Clean Chat UI  
✅ Clear Chat Option  
✅ Conversation Memory

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai_chatbot.git
cd ai_chatbot
```

---

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Create `.env` File

Create a `.env` file in the root folder.

```env
GROQ_API_KEY=your_api_key_here
```

---

# ▶️ Run the Application

```bash
python app.py
```
